# Emlek — 個人 AI 長期記憶庫

本機、單一使用者的文字記憶庫。讓你的 AI（Claude、Codex 或其他支援 MCP／命令列的平台）在你要求時把內容存起來，之後能找回並附上來源。

**狀態：規劃中。尚無可安裝的程式；以下為預期用法，尚未可用。**

## 它做什麼

- 你說「記住這個」「幫我記一下」，AI 才會存；「我上週記住了文法」這類敘述不會觸發。拿不準時 AI 會先問你。
- 原文不被覆蓋：修改會新增版本，舊版本仍在。
- 原文、AI 整理、AI 推論分開標記；不知道的作者與日期就標未知。
- 全文搜尋，支援中日英。
- 一般刪除只是「隱藏」，可以恢復。真正抹除需要你事前登記的特別指令（目前為「完全刪除」），AI 還會用「是／否（無法回復）」再問一次。
- 資料全在一個資料夾、主體是一個資料庫檔。`backup` 產生單一備份檔（可加密碼），`restore` 在新電腦還原，`export` 輸出 JSON／Markdown 作為脫離本軟體的保險。

## 不做什麼

不上雲、不做多使用者、不做身分隔離或授權系統、不做向量搜尋或知識圖譜。這些在舊完整版藍圖中有設計，需要時再取用。
