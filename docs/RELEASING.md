# 版本、提交與推送

## 每批與集中定版

每批驗證後本機提交，英文 type: summary 加環境署名，只選本批檔案。文件／測試／內部整理不逐批升版。Unreleased 描述相對前版的最終行為，合併同主題、移除尚未發布前已被取代的說法；已發布版本不改寫。

使用者驗收一組功能後按需要集中定版：修錯升 patch；新增相容功能升 minor；破壞相容升 major。minor／major 及 1.0、發布／tag 先經使用者核定。0.x 也須說明不相容影響及資料升級／備份路徑，不犧牲舊備份。

`python scripts/workflow.py version patch` 同步 pyproject.toml、src/emlek/__init__.py 與 uv.lock 的 emlek 套件版本；minor／major 只在核定後使用。同批更新 CHANGELOG，重新 full 驗證、提交；腳本不產 tag 或對外發布。

## 一般推送

使用者確認通過後，Agent 自動 close、驗證、提交整理並執行 workflow.py push，不另問。這項長期政策取代未發布期間每次另問推送的舊規則（D99）；工作清單不構成新功能授權。

只在 main 普通推送 origin/main；仍有進行中／待驗收工作、內容變更使驗證失效、未提交變更時阻擋。先完成其他批次驗收，不擅自結案。不強推、不改寫歷史、不動其他分支。一般推送不是發布，既有敏感詞 hooks 必須執行。

## 獨立版本

程式版在 pyproject.toml／__init__.py；資料庫版由遷移編號／PRAGMA user_version 管理，已發布遷移不可改；匯出格式由 export.FORMAT_VERSION 管理，不相容時升版並保留舊格式讀取；工具介面由 api_version 管理，只加相容欄位不升版。提示版本在 MCP，改行為時同步完整規則。

## 對外發布關卡

使用者明確要求才啟動，不因工作清空自行發布：完整建置／測試、乾淨環境安裝／升級／移除、依賴及 SQLite WAL 修補線檢查、受控備份還原演練、文件／授權／限制與標記敏感詞檢查。真實備份仍須貼出路徑並授權。CI 未採用，不假定已完成或強制新增服務。檢查全過且核定發布後才切版本、打 tag／發布，不覆寫既有 tag。
