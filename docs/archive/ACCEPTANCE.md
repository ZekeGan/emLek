## 3. 正式 V1 附加條件

- P4 的 manifest 掃描可跨重啟續作，無漏頁／重複，完整字節範圍可驗證。

- coverage 實際可核算，partial 不宣稱 complete；新增／修正／刪除的 snapshot 規則有測試。
- 重新解讀另建衍生 Record；新模型不改寫舊歷史，分析不自動永久保存。
- Token 最佳化如果保留就通過 G 門檻；不通過則停用該最佳化，完整批次流程仍必須通過。
- 全部 MVP gate 保持通過，無未說明的重大失敗測試；正式發布證據有程式版本、lock、fixture、環境和完整結果。

真實代表性語料如果未獲授權，明列未測且不宣稱個人真實語料準確率。這不允許省略合成／公開金標、實際 Agent 與安全驗收。

## 4. 阻擋發布的缺陷

任一丟失已回報提交、原文改寫、錯誤 provenance／版本、偽造確認、越權讀寫、隱私內容洩漏、舊備份復活、無法還原有效備份均阻擋發布。不得以大多數測試成功抵銷。

效能未達預定門檻須修復，或以 ADR 提供實測與需求理由正式調整；不能事後偷偷改數字。權限／資料完整性門檻不得因工具難以測試而下調。
