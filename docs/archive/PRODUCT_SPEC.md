# 正式產品規格

狀態：MODE A 規格；版本 0.1；日期 2026-10-28。規格描述預期行為，不是已完成功能。

2026-10-29 權限修訂：依使用者最新要求，可信任 Agent 首次授權後可持續讀取授權範圍；明確保存指令可在有限委派內直接提交。取代逐會話讀取授權與逐筆人工保存核准；其餘 v0.5 原則、資料模型與產品範圍維持。來源原文保留不改，確認方式的本次調整以 SECURITY §4–5、DATA_CONTRACT §5–6 為準。

## 產品與成功條件

由個人持有、至少五至十年可遷移使用的文字記憶基礎設施。單一 AI Agent 是主要入口；資料正確性、授權與恢復由確定性程式保證，模型僅負責理解、提出內容與有來源的分析。

不強制日記／研究／待辦等分類；`content_kind` 表達來源性質而非主題分類。正文接受任何領域的文字。未知資料保持未知，沒有找到紀錄不能推導事情未發生。

## MVP、正式 V1 與延後範圍

- **P1 垂直切片**只證明保存至新會話取回，不稱完整 MVP。
- **MVP 功能候選**為 P0–P3 完成；必須再通過 R 私人發布關卡才可投入真實個人資料。
- **正式 V1**為 MVP 加 P4 的長期分析、覆蓋與可續作能力，並通過全部 V1 驗收。
- **P5 按需**：Embedding、Claims/Evidence、Knowledge Graph、活動 State Projection、自動摘要、保守智慧觸發。不是 V1 完成的必要條件。
- 不建立多 Agent 產品架構、大型 GUI、二進位附件平台、雲端常駐服務、同步協作平台或自製搜尋／備份引擎。

## 使用體驗的具體取捨

受信任 owner 介面沿用於首次登記、持續讀取／有限保存授權、撤銷與未委派操作。授權內的讀取不因查詢或正常會話重啟再次確認；使用者清楚要求保存時，可信任 Agent 可直接完成，日常新增無額外人工核准畫面。Core 仍驗身分、action／scope、目標版本與撤銷狀態，並明記委派授權不等於人類看過 payload。現有請求無法獨立證明使用者意圖，由首次授權明確委派這項判斷，不以假證明取代保護。原文核對／事實確認、越權與高風險操作維持原規則。可用性與限制驗收見 TEST_PLAN W/S/U。
